# LinkedinChi Landing Page

واجهة عربية كاملة لخدمة لنكدنجي (LinkedinChi) توضح الفكرة، المزايا، الباقات، والعروض الخاصة.

## تشغيل المشروع محلياً

1. تأكد من وجود Python 3 على جهازك.
2. من داخل مجلد المشروع شغل الخادم البسيط:
   ```bash
   python3 -m http.server 8000
   ```
3. افتح المتصفح وتوجه إلى [http://localhost:8000](http://localhost:8000). سيتم تحميل الصفحة الرئيسية تلقائياً من `index.html`.
4. إذا كنت تريد الوصول مباشرة إلى الملف القديم `tinker.html` فسيتم تحويلك تلقائياً إلى الصفحة الجديدة.

## بنية المجلدات

- `index.html`: صفحة الهبوط الرئيسية.
- `tinker.html`: ملف تحويل يحافظ على الرابط القديم.
- `css/`: ملفات الأنماط.
- `image/`: الأصول والصور المستخدمة بالخلفيات.
- `webfonts/`: خطوط أيقونات Font Awesome.

## ملاحظات

- التصميم يدعم الاتجاه من اليمين إلى اليسار (RTL) مع خطوط عربية من Google Fonts.
- تم تضمين قائمة تنقل متجاوبة مع زر للهاتف المحمول وسكربت بسيط لتفعيلها.
- جميع روابط الدعوة للفعل تقود إلى استمارة Google المرفقة بالخدمة.
