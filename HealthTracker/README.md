# HealthTracker (SwiftUI + Core Data)

مشروع تطبيق تتبع صحي شخصي يعمل بالكامل بدون اتصال إنترنت، باستخدام SwiftUI و Core Data مع بنية MVVM ودعم RTL.

## المتطلبات
- Xcode 15 أو أحدث
- iOS 17+ (محاكي أو جهاز حقيقي)
- لغة Swift 5

## هيكل المجلدات
- `HealthTrackerApp.swift`: نقطة الدخول للتطبيق.
- `CoreData/PersistenceController.swift`: إعداد حاوية Core Data بنموذج برمجي.
- `Models/`: كائنات NSManagedObject لكل نوع بيانات (الطعام، المشروبات، النوم، الأمعاء).
- `ViewModels/`: منطق العرض وإدارة الحالة لكل وحدة.
- `Services/`: خدمات تقدير السعرات والمشروبات وتحليل النوم والبراز.
- `Views/`: الشاشات الرئيسية (اليوم، الإدخال، السجل، التحليلات، الإعدادات) ومكونات مثل PhotoPicker.
- `Resources/Localizable.strings`: ملف تهيئة للترجمة العربية وإضافة لغات مستقبلًا.

## إنشاء المشروع في Xcode
1. افتح Xcode واختر **File > New > Project...** ثم اختر **App**.
2. الاسم: `HealthTracker`، الواجهة: **SwiftUI**، دورة الحياة: **SwiftUI App**، لغة: **Swift**.
3. اضبط **iOS Deployment Target** إلى **iOS 17.0** أو أحدث من إعدادات المشروع.
4. أنشئ مجلدات بنفس الهيكل أعلاه داخل مجموعة المشروع.
5. انسخ ملفات Swift و Localizable من هذا المجلد وضعها في المواقع المطابقة داخل المشروع.
6. تأكد من تمكين Capability الوصول للصور (Photo Library) إذا طُلب.

## التشغيل على المحاكي أو الجهاز
- للمحاكي: اختر جهاز iPhone 13 (أو مشابه) من شريط الأجهزة واضغط **Run**.
- لجهاز حقيقي: وصل الجهاز، وثق الشهادة، ثم اختره من قائمة الأجهزة واضغط **Run**.
- لضمان RTL، اضبط لغة الجهاز أو المحاكي إلى العربية من الإعدادات.

## ملاحظات RTL والتعريب
- كل النصوص في الواجهة بالعربية ومحاذاة لليمين.
- تم ضبط البيئة على `layoutDirection = .rightToLeft` و `Locale("ar")` لضمان التجربة العربية.
- استخدام `Localizable.strings` يمهّد لإضافة لغة ثانية مستقبلًا.
